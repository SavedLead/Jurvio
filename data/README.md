# Supreme Court justice analytics: source data

Downloaded 2026-11-01 (America/New_York). Every file below is used as published;
`scripts/import-scdb.ts` records each file's SHA-256, version, source URL and
citation text in `scotus_dataset_release` when it imports it.

Labeling rule for anything built on this data: ideology is "liberal/conservative
as coded by the Supreme Court Database" or a Martin-Quinn score. Never label a
justice, vote or case by political party.

Democracy), NSF-funded. Site: https://scdb.la.psu.edu (old host scdb.wustl.edu
no longer serves data). Downloads sit behind a Cloudflare browser check, so they
were fetched with a real browser, not curl.

Citation required by SCDB (https://scdb.la.psu.edu/how-to-cite-us/), always with
the specific version:

> Harold J. Spaeth, Lee Epstein, Michael J. Nelson, Andrew D. Martin, Jeffrey A.
> Segal, Theodore J. Ruger, and Sara C. Benesh. 2026. Supreme Court Database,
> Version 2026 Release 01. URL: https://scdb.psu.edu

(and "Version Legacy 07" for 1791-1945 data). License: the site publishes no
license text; it asks every user to cite the database and version. Treat
redistribution of the raw files as needing attribution; open question whether
public display of derived statistics needs anything more.

Codebook: https://scdb.la.psu.edu/online-codebook/ . Value labels used by
migration 0186 (`scdb_code_label`) are copied from the codebook pages for vote,
opinion, direction, majority, decisionDirection, decisionType and issueArea.
Data quirks handled, not guessed: firstAgreement/secondAgreement = 0 (not a
codebook value) is stored as NULL; 25 Legacy 07 rows with justice = -99 are
skipped and counted.

## Martin-Quinn scores

Andrew D. Martin (Washington University) and Kevin M. Quinn (Emory). Site:
https://mqscores.wustl.edu/measures.php (Cloudflare; the origin was intermittently
down with error 521 on 2026-11-01).

estimates run through the October 2024 term). The site recommends `post_mn`

> Andrew D. Martin and Kevin M. Quinn. 2002. "Dynamic Ideal Point Estimation via
> Markov Chain Monte Carlo for the U.S. Supreme Court, 1953-1999." Political
> Analysis 10:134-153.

License: none published; cite as above.

## Justice biography and appointments (FJC)

`scotus/justices.json` (committed) is generated by
`scripts/scotus/build-justice-roster.py` from the SCDB justice list
(https://scdb.la.psu.edu/online-codebook/majority-opinion-writer/, saved as
`scdb/codebook-majority-opinion-writer.html`, not committed) and the Federal
Judicial Center Biographical Directory exports (not committed; U.S. government
work, public domain):

- https://www.fjc.gov/sites/default/files/history/federal-judicial-service.csv (`2c124e5b008c501ff21d371c3affe4a1c3fe426c21e13ff849ad837af08211f7`)
- https://www.fjc.gov/sites/default/files/history/demographics.csv (`01f5638d1661b90696165e747863c34fd0a57f467d8c2caf67b6e78e6b8f0cb1`)

118 SCDB justices map to FJC nids; all 121 FJC Supreme Court appointment rows are
attached (promotions to Chief Justice stay on one SCDB id; Rutledge and Hughes
have two SCDB ids). The party of the appointing president is not copied.

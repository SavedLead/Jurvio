# JurvioJurvio makes public litigation searchable, understandable, and connected.## Current scopeThis branch implements the approved foundation and first opinion-research slice:- typed Next.js modular-monolith foundation;- PostgreSQL canonical schema and migrations;- deterministic, versioned case-status engine;- immutable source-artifact storage contract;- CourtListener/RECAP docket ingestion vertical slice;- CourtListener opinion-cluster ingestion with sanitized, citation-linked HTML;- readable opinion pages and source-grounded PostgreSQL full-text search;- privacy-safe human, search-crawler, AI-bot, and agent demand measurement;- publication controls, outbox events, health endpoint, and CI.Ingested records remain **draft**. Ingestion never makes a record public automatically.## Local setup1. Install Node.js 22 and pnpm 10.13.1.2. Copy `.env.example` to `.env.local`.3. Start PostgreSQL with `docker compose up -d postgres`.4. Run `pnpm install`.5. Run `pnpm db:migrate`.6. Run `pnpm dev`.Run all checks with `pnpm verify`.The production container is defined in `Dockerfile`. Deployment sequencing, readiness checks, backups, rollback, and cost gates are documented in `docs/33-staging-deployment-runbook.md`.The pre-DigitalOcean production package is in `docker-compose.production.yml`, `.github/workflows/deploy-production.yml`, and `docs/38-production-readiness-checklist.md`. Production secrets belong only in GitHub's protected `production` environment or `/opt/jurvio/.env.production`; they must never be committed.## CourtListener ingestionSet `COURTLISTENER_API_TOKEN` when required, then run:- `pnpm ingest:docket <courtlistener-docket-id>` for a complete docket slice;- `pnpm ingest:opinion-cluster <courtlistener-cluster-id>` for one opinion cluster;- `pnpm ingest:opinions --court scotus --since 2025-01-01 --limit 10 --order newest` for a small, rate-friendly first batch;- add `--order cited` to prioritize the most-cited opinions in the selected court and date window.The adapter stores each unmodified response, records its hash and provenance, and normalizes only supported fields. Opinion HTML is deterministically sanitized before it can reach the reader. New records stay draft until the publication policy approves them.## Internal publication console`/internal/publication` is protected by Cloudflare Access JWT validation and Jurvio role-based authorization. Bootstrap authorized staff with `pnpm internal:user <email> <role>` after applying migrations. See `docs/32-internal-access-runbook.md` for setup and verification.## Architectural invariants- PostgreSQL is canonical; search and AI outputs are rebuildable projections.- Raw source artifacts are immutable and content-addressed.- Unknown facts remain unknown.- Status is deterministic and source-backed.- AI cannot determine status, publication, privacy, or identity.- Public routes return only records approved for publication.See `docs/30-final-architecture-approval-index.md`.
